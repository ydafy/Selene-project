# Security policy

Selene moves real money and stores personal data. This repository is public, so vulnerabilities are handled in private until they are fixed and deployed.

## Reporting a vulnerability

Report it through **Security > Report a vulnerability** on GitHub ([direct link](https://github.com/ydafy/Selene-project/security/advisories/new)). Only the maintainer can see the report.

Do not open a public issue, pull request, or discussion about it, and do not test against the production project or real accounts.

Include what is affected, how to reproduce it, and what an attacker could do. The maintainer answers as soon as possible; this is a single-maintainer project, so there is no fixed response time.

## What counts as a vulnerability

Anything that lets someone read or change data they should not, move or block money, skip authentication or authorization, reach secrets, or abuse the platform's server credentials. Ordinary bugs go through the "Finding" issue form.

## Disclosure

A fix is deployed first. Details become public only after that, usually by publishing the advisory.
