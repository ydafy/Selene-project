## Specs

- S1 (#78): "The English and Spanish versions of two locale files no longer have the same keys [...] `checkout.json`: in English, `validation` and `dialogs` are nested inside `actions` [...] while in Spanish they sit at the top level [...]. `errors.stockTitle` and `errors.stockMsg` exist only in Spanish. `common.json`: `actions.goBack` exists only in Spanish." "The fix is to move the English keys to the same paths as Spanish, add the missing English strings, and add a parity test for every locale file so the next drift fails CI."
- S2 (#72): "Several mobile screens call translation keys in the `common` namespace that do not exist in the locale files, so the user sees the raw key". Listed call sites: `app/(tabs)/profile.tsx:157` and `app/profile/edit.tsx:87` (`common:cancel`, existing key is `common:dialog.cancel`); `app/sell/images.tsx:74` (`common:actions.cancel`); `app/product/[id].tsx:117` (`common:actions.goBack`, English only); `app/product/[id].tsx:206` (`common:states.unknown`); `components/features/search/FilterModal.tsx:275` (`common:actions.retry`); `components/features/sell/DynamicSpecField.tsx:123` (`common:errors.required`); `components/features/sell/SellDetailsForm.tsx:182` (`common:select`). Every one shows text in English and Spanish.
- S3 (#51): "Opening a product from a list never shows the product instantly from cache [...] `useProduct` tries to reuse the listing already loaded by a list (`placeholderData`) with `queryClient.getQueryData(['products'])`, an exact-key lookup. No list is ever cached under `['products']`". "The same key also includes options that do not change the data, such as `enabled`, so the same list can end up under more than one cache entry." Prefix users `useProductManagement.ts:88` and `:162` (`['products']`) must keep working.
- S4 (#62): "The shipment banner in the order detail (`OrderActionCard`) picks its text from the **order** status before the **shipment** status." "A cancelled shipment inside an order whose status is `dispute` (another shipment has a dispute) shows the dispute copy instead of the cancelled banner". "The order-level `refunded` branch [...] is checked before the cancelled branch, so a seller of a cancelled shipment in an order marked `refunded` would read the dispute text." A cancelled shipment always shows its cancelled banner.
