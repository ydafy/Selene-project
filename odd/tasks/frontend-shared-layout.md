# Frontend shared/ by topic, with @/ imports (#291)

Item 7 of roadmap #228, the last one. Keeps `apps/frontend/src/shared/` for code that two or more features (or `app/` and a feature) use, groups `shared/ui` and `shared/utils` by topic, and converts relative imports that leave their top-level folder to `@/`, kept by an ESLint rule. Branch `refactor/frontend-shared-layout`, from `origin/main` 545a542a.

## Specs

- S1 (issue #291, item 1): "**Only shared code in `shared/`.** List every file under `apps/frontend/src/shared/` with the features that import it. A file used by one feature only moves into that feature (`features/<domain>/{components,hooks,lib,logic,utils}`), with `scripts/dev/move-files.ts`." Corrected by L2: `shared/utils/connect-onboarding-urls.ts` stays, because its only importer is `shared/hooks/use-connect-onboarding.ts`, which `app/`, profile, and orders use; moving it would make `shared/` import a feature. A file that `app/` imports stays in `shared/`.
- S2 (issue #291, item 2): "**Group the large folders by topic, not by type.** `shared/ui` has 47 files at the top level plus `icons/` and `product/`; `shared/utils` has 31 files (14 tests). Group them into topic folders (for example `feedback/`, `form/`, `media/`, `layout/` for UI, and `money/`, `dates/` for utils), one level deep, with no one-file folders. Smaller folders (`hooks/` with 21, `lib/`) stay flat unless a clear cluster shows up."
- S3 (issue #291, item 3): "**`@/` for imports that leave their top-level folder** (`app/`, `features/<domain>/`, `shared/`), converted in one pass and kept by an ESLint rule forbidding `../../`, as admin-web does after #221 (S11 of `odd/tasks/admin-web-layout.md`). This absorbs #290." By L2 the rule is the admin-web one (any relative import that leaves its top-level folder, not the `../../` string), and it also checks the first string argument of `mock.module(...)`, `jest.mock(...)`, and `require(...)`.
- S4 (issue #291, item 4): "Document the grouping rule in `docs/conventions.md` (\"Frontend layout\")."
- S5 (L2, amended by L9 and L11): `shared/utils/format.ts` splits into a money module and a dates module. Money is a topic folder (`utils/money/`); the date helpers sit in `utils/format-date.ts` until a second date module exists, because a one-module folder breaks S2.
- S6 (issue #291, Done when): "`bun test` count unchanged, lint, typecheck, format:check and knip green, the frontend boundary test (`apps/frontend/frontend-import-boundaries.test.ts`) passes, and no file in `shared/` is imported by fewer than two features unless the feature document records why." New tests added by this work raise the count; the baseline plus the new tests must match.
- S7 (issue #291): "Plan it in a feature document when it starts (inventory first, one topic per commit)." "Close it with `Closes #<this issue>` in its PR."
