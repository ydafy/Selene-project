# Bruno API collection

Versioned, runnable HTTP requests against the local Supabase stack, so Edge Functions and RPCs can be exercised by hand (Bruno app) or by agents (Bruno CLI) without rewriting curl commands.
Setup only: the first requests encode checks already proven in this repo; no product code changes.

## Specs

- S1: "okey dale con burno aahora si" — Bruno is set up in the repository.
- S2: Agreed earlier: Bruno keeps requests as files inside the repo (no account, no cloud), the maintainer opens them in the desktop app and agents run them with the CLI.
- S3: Requests target the local stack of the current worktree (stack mode gives each worktree its own ports); secrets never enter git.
- S4: The first collection repeats the manual checks of this session as runnable requests with assertions.
