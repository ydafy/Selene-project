## What is Selene?

Selene is a P2P marketplace for buying and selling used PC hardware in Mexico.

The project was built from the ground up as a real product, combining a mobile marketplace with verification, payments, shipping, seller workflows, and centralized administrative operations.

The goal is not only to provide a place to buy and sell hardware, but to create a more trustworthy experience around second-hand transactions.

---

## Core Workflow

```text
Discover
   ↓
Purchase
   ↓
Seller Ships
   ↓
Delivery
   ↓
Buyer Confirms
   ↓
Payment Released
```

The buyer's payment is held until the order is confirmed. Once the buyer confirms the order, a release request is created in the administrative dashboard, where the payment can be released to the seller.
