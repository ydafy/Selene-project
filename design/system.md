# Design system (token catalog)

Snapshot of the tokens and component rules that already exist in code, for design explorations under `design/`. It is generated by the Gentle Design sync and records only values found in the sources below.

- Intent, principles, and the "Never" list live in `DESIGN.md`. Read it first; it wins over this file.
- The code wins over both. When a source changes, re-run the sync (`gentle_design` `list` reports stale sources).

## Typography

One family: Montserrat (Regular, Medium, Bold). Admin: `--font-montserrat` in `index.css`, applied to `body`. App variants (`index.ts`, Restyle `textVariants`):

| Variant        | Weight  | Size / line height | Color           |
| -------------- | ------- | ------------------ | --------------- |
| `header-2xl`   | Medium  | 36 / 40            | `textPrimary`   |
| `header-xl`    | Medium  | 28 / 36            | `textPrimary`   |
| `subheader-lg` | Medium  | 22 / 29            | `textPrimary`   |
| `subheader-md` | Medium  | 16 / 24            | `textPrimary`   |
| `body-lg`      | Regular | 16 / 28            | `textPrimary`   |
| `body-md`      | Regular | 14 / 24            | `textPrimary`   |
| `body-sm`      | Regular | 12 / 16            | `textPrimary`   |
| `caption-lg`   | Regular | 14 / 20            | `textSecondary` |
| `caption-md`   | Regular | 12 / 16            | `textSecondary` |
| `defaults`     | Regular | 16 / 24            | `textPrimary`   |

Admin uses Tailwind sizes: `text-xs` / `text-sm` for data, `text-xl` for modal titles, `text-2xl font-bold` for a panel's main figure. Money and counts use tabular figures.

Artboards cannot load web fonts. Use the stack `Montserrat, system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`: it renders Montserrat only where it is installed locally and falls back to a system font otherwise.

| Token  | Spacing (app) | Radius (app) |
| ------ | ------------- | ------------ |

| `xl`   | 40            | 40           |

React Native Paper `roundness` is `s` (8); Paper multiplies it per component. Admin radii: `rounded-xl` (12) for buttons and inputs, `rounded-2xl` (16) for panels and cards, `rounded-3xl` (24) for `Modal`, `rounded-full` for pills and badges.

## Shadows and motion

- Depth comes from surface steps and hairline borders. App shadows use `shadow` (`#000000`) with `shadowOpacity`; admin modals use `shadow-2xl`.
- Admin page content fades in (`fadeIn`: opacity 0 to 1, `translateY(4px)` to 0). Reduced motion collapses every animation and transition (`index.css`).

- The admin has no `warning` or `errorSubtle` token (already listed in `DESIGN.md`, "Known gaps").
